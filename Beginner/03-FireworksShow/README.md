## الحكاية

تخيّل عرض ألعاب نارية حقيقي.

شخص واحد واقف على الأرض بيولّع الفتيل، وآلاف واقفين بعيد بيتفرجوا. **واحد بس بيتحكم**، والكل بيشوف **نفس اللحظة** بالظبط.

المشروع ده بيعمل النسخة الرقمية من اللحظة دي:

- أول واحد يفتح الصفحة يبقى **المُطلِق (Host)**.
- كل واحد تاني يفتحها يبقى **مشاهد (Spectator)**.
- المُطلِق يدوس، فالانفجار يظهر على كل الشاشات المفتوحة في نفس الوقت.
- المُطلِق يقفل الصفحة، فالدور **بيتنقل تلقائيًا** لأول واحد متصل بعده.

مافيش تسجيل دخول، ولا داتابيز، ولا إعدادات. المنطق كله فكرته بسيطة: *أول واحد وصل، مسك الزمام.*

## ليه المشروع ده موجود؟

في المشروعين اللي فاتوا من السلسلة، **أي حد متصل** كان يقدر يبعت الحدث، يعني الكل كان عنده نفس الصلاحية.

هنا لأول مرة بيبقى فيه **فرق بين الناس**. وده أول تماس ليك مع مفهوم **Authorization**، بس بشكل مبسّط جدًا من غير Login ولا Tokens ولا Policies.

| المشروع | السؤال اللي بيجاوب عليه |
|---|---|
| #1 | إزاي أخلّي الحدث يوصل من السيرفر للمتصفح؟ |
| #2 | إزاي أخلّي الرسالة توصل لكل الناس المتصلة؟ |
| **#3 (إحنا هنا)** | **إزاي أخلّي واحد بس يقدر يبعت، والباقي يتفرج؟** |
| #4 (قادم) | إزاي أتحقق من هوية اللي بيبعت فعليًا؟ |
| #5 (قادم) | إزاي أقسّم الناس على غرف مختلفة؟ |

## المميزات

- **دور واحد للمُطلِق:** أول اتصال بياخد الصلاحية، وكل اللي بعده بيتفرج.
- **تنقّل تلقائي للدور:** لو المُطلِق خرج، الدور بيروح لأول واحد متصل بعده.
- **بث لحظي:** SignalR عبر WebSockets عشان الانفجار يوصل لكل الشاشات في نفس الوقت تقريبًا.
- **انفجارات SVG:** كل انفجار بيتولد بأشعة عشوائية، وحلقة ممتدة، ونواة بتلمع.
- **أفق مدينة عربية:** مآذن وقبة وشبابيك مضيّة بتفرفر بشكل عشوائي.
- **موجات بث حية:** بتنبض من نقطة الإطلاق في الأفق.
- **ثنائي اللغة:** عربي وإنجليزي مع تبديل كامل بين RTL وLTR.
- **احترام الوصول (Accessibility):** `prefers-reduced-motion` و`focus-visible` و`aria-disabled`.
- **إعادة اتصال تلقائية:** لو النت قطع، الـ client بيرجع لوحده بعد 3 ثواني.

## كيف يعمل؟

### المخطط العام

```
   Host                                   Spectator
     |                                        |
     |  invoke("Launch")                      |
     v                                        |
 +----------------------------------------+   |
 |        ASP.NET Core SignalR Hub        |   |
 |   FireworksHub  (/hubs/fireworks)      |   |
 |                                        |   |
 |   _hostConnectionId = ...              |   |
 |                                        |   |
 |   Clients.All.SendAsync(               |   |
 |     "FireworksLaunched", event)        |   |
 +--------------------+-------------------+   |
                      |                       |
          +-----------+-----------+-----------+
          v                                   v
        Host                              Spectator
     (explosion)                         (explosion)

        نفس اللحظة، من غير تأخير محسوس
```

### دورة حياة الاتصال

```
1. المتصفح يفتح الصفحة
   connection.start()  ->  POST /hubs/fireworks/negotiate

2. السيرفر يستقبل الاتصال في OnConnectedAsync
   هل _hostConnectionId فاضي؟
     - نعم : خزّن الـ ConnectionId، يبقى Host
     - لا  : يبقى Spectator

3. السيرفر يبعت للمتصفح
   "RoleAssigned"        (true / false)
   "RecentLaunchesSync"  (آخر الانفجارات)

4. الـ client بيحدّث الواجهة
   body[data-role="host"]       ->  الزرار يلمع
   body[data-role="spectator"]  ->  الزرار مطفي
```

### أسماء الأحداث (العقد بين الباك والفرونت)

| الحدث | الاتجاه | البيانات | إمتى بيتبعت |
|---|---|---|---|
| `RoleAssigned` | Server → Client | `boolean` | بعد كل اتصال جديد |
| `RecentLaunchesSync` | Server → Client | `LaunchEvent[]` | بعد الاتصال، لمزامنة الحالة |
| `FireworksLaunched` | Server → All | `LaunchEvent` | لما المُطلِق يدوس |
| `LaunchRejected` | Server → Caller | — | لما حد مش Host يحاول يطلق |
| `Launch` (method) | Client → Server | — | نداء من الفرونت للباك |

> **قاعدة مهمة:** الباك والفرونت مش عارفين حاجة عن بعض غير **أسماء الأحداث دي**. الـ Hub مش عارف إن فيه CSS، والـ CSS مش عارف إن فيه SignalR. الخط الرفيع اللي بينهم هو اللي بيخلي المشروع سهل الصيانة.

### العنصر المميز

**زرار الإطلاق الدائري** بحلقات نابضة، متحط عمدًا في قلب الصفحة، وكل حاجة تانية حواليه أهدى عشانه.

الزرار بيظهر في كل الحالات، بس بمستوى شفافية مختلف:

- **المُطلِق:** لمعة كاملة وتوهج وحلقات بتنبض.
- **المشاهد:** مطفي ورمادي، ولو دوست عليه بيهتز وتظهرلك رسالة.
- **في انتظار الاتصال:** مطفي مع نص "جارٍ الاتصال".

### الرسومات

كل الرسومات SVG بيتولّد ديناميكيًا، مش صور:

- **أفق مدينة عربية:** قبة ومئذنتين وأبراج حديثة وشبابيك بتفرفر.
- **موجات البث:** خمس حلقات بيضاوية بتنبض من نقطة واحدة في الأفق.
- **الانفجارات:** أشعة عشوائية، وحلقة ممتدة، ونواة بتلمع، وشرارات طايرة.

### الخطوط

- **Display:** `Anton` لعنوان "FIREWORKS SHOW".
- **Body:** `Work Sans` و`IBM Plex Sans Arabic` للنصوص الإنجليزية والعربية.

## تشغيل المشروع

### المتطلبات

- .NET 9 SDK
- متصفح حديث (يُفضّل Chrome أو Edge)
- Live Server أو أي static host بسيط للفرونت (زي إضافة VS Code)

### حزم NuGet

**مفيش حزم NuGet إضافية مطلوبة للباك.** SignalR جزء من الـ shared framework الخاص بـ `Microsoft.AspNetCore.App`، فمجرد استخدام `Microsoft.NET.Sdk.Web` في ملف الـ `.csproj` بيكفي.

أما الفرونت فبيستخدم `@microsoft/signalr@8` عن طريق Import Map، فمش محتاج `npm install`.

### 1. شغّل الباك

```bash
git clone https://github.com/your-username/fireworks-show.git
cd fireworks-show/FireworksShowAPI

dotnet dev-certs https --trust   # مرة واحدة فقط، لشهادة HTTPS المحلية
dotnet run
```

المفروض تشوف:

```
Fireworks Show API is running
Now listening on: https://localhost:7272
```

افتح `https://localhost:7272/` في المتصفح واقبل الشهادة، وبعد كده اقفل التاب.

### 2. شغّل الفرونت

```bash
cd fireworks-show/client
# افتح المجلد ده في VS Code واعمل "Go Live" من Live Server
# المفروض يشتغل على http://127.0.0.1:5500
```

### 3. جرّب الدورين

افتح الصفحة في **تابين** مختلفين (أو متصفحين):

1. **التاب الأول** هيبقى المُطلِق (الزرار لامع).
2. **التاب التاني** هيبقى مشاهد (الزرار مطفي).
3. دوس على الزرار في التاب الأول، والاتنين هيشوفوا نفس الانفجار.
4. جرّب تدوس في التاب التاني، هيهتز وتظهرلك رسالة "انت مش المُطلِق".
5. اقفل التاب الأول، والتاب التاني هيبقى المُطلِق الجديد تلقائيًا.

## اللي هتتعلمه

- **تربط متصفح بسيرفر .NET** عبر SignalR، مع اتصال مستقر وإعادة اتصال تلقائية.
- **تحتفظ بحالة (State) على مستوى الـ Hub:** مين المُطلِق، ومين متصل، وإمتى ينقل الدور.
- **تفصل الطبقات:** الـ Hub مش عارف حاجة عن الشاشة، والـ client مش عارف تفاصيل السيرفر، وبينهم أسماء أحداث بس.
- **تربط حالة السيرفر بحالة الواجهة:** `body[data-role]` بيتغير والـ CSS بيتصرّف لوحده.
- **تكتب واجهة بتوصّل معنى** مش بس بتعرض بيانات.
- **تتعامل مع الفشل بهدوء:** رسالة inline واهتزاز بدل `alert()` المزعجة.

## أفكار للتوسّع

- **غرف متعددة (Rooms):** كل مجموعة ليها أفقها ومُطلِقها لوحده.
- **تسجيل هوية:** استخدم JWT بدل "أول واحد وصل".
- **مؤثرات صوتية:** صوت انفجار خفيف مع كل طلقة، مع زر كتم.
- **سجل الانفجارات:** اعرض آخر 20 انفجار تحت الأفق مع وقتها.
- **فترة تهدئة:** 3 ثواني بين كل إطلاق والتاني لمنع السبام.
- **عدد المشاهدين:** "14 واحد بيتفرجوا دلوقتي".
- **أنواع انفجارات:** اختيار الشكل قبل الإطلاق (قلب، نجمة، حلقة).
